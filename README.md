## Завдання (Варіант 3): Контроль витрат електроенергії

Створіть програму для аналізу споживання електроенергії за сім днів.

Користувач вводить сім значень споживання в кВт·год.

Необхідно:
- обчислити загальне споживання;
- визначити день із найбільшим споживанням;
- знайти середнє добове споживання;
- підрахувати кількість днів, коли споживання перевищувало середнє;
- визначити, на скільки кВт·год найбільше значення перевищує найменше.
